Domande frequenti

Serve un server o un hosting a pagamento?

No. Sito e pannello girano gratis su GitHub Pages. Paghi solo il dominio, se ne vuoi uno tuo.

Come arrivano le prenotazioni?

Via email con Web3Forms (gratis) o su Telegram con un webhook. I pazienti possono anche scrivere su WhatsApp, Viber o chiamare.

Posso usare il mio dominio?

Sì. Aggiungi un file CNAME e un record DNS; la guida spiega come.

Chi può modificare il sito?

Chi ha il token GitHub dello studio. Il token resta solo nel browser di chi modifica.

Ci saranno altri design?

Sì. Il motore è comune e i nuovi design si aggiungono come temi. Ora sono due: Lumen per studi generali e Smile Line per l'ortodonzia.

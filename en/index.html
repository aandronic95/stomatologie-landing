Frequently asked questions

Do I need a server or paid hosting?

No. The site and the admin run free on GitHub Pages. You only pay for a domain if you want your own.

How do booking requests reach us?

By email through Web3Forms (free) or in Telegram through a webhook. Patients can also message on WhatsApp, Viber or call.

Can I use my own domain?

Yes. Add a CNAME file and one DNS record; the guide explains how.

Who can edit the site?

Anyone with the clinic's GitHub token. The token is stored only in the editor's browser.

Will there be other designs?

Yes. The engine is shared and new designs are added as themes. The first design is Lumen.
